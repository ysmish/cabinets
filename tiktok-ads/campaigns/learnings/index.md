# 📈 Learnings

Weekly notes from the [[../../.agents/growth-analyst|📈 Growth Analyst]]. One file
per week, written by [[../../.jobs/weekly-creative-review|Weekly Creative Review]]
every Monday at 10:00.

| File | What it is |
|---|---|
| `weekly-<YYYY-MM-DD>.md` | What was tested, what it suggests, what to test next |

## What a note contains

1. **The week in one line**
2. **What was tested** — grouped by angle, not by clip. Three clips of the same
   argument is one test.
3. **What the results suggest** — with sample sizes. Anything under 1000
   impressions is recorded as unmeasured rather than interpreted.
4. **Spend and waste** — total cost, cost per angle tested, and any spend that
   produced duplicate learning.
5. **Next three angles**, ranked, each with what result would change the call.

One page maximum.

## How this closes the loop

Monday's note names the angle that Wednesday's
[[../../.jobs/weekly-ad-prep|Ad Prep]] job writes into a new campaign. The
"Angles worth testing" list in [[../../audience/index|Audience]] is updated from
here, so it improves over time instead of going stale.

> **Note on data.** This cabinet has no TikTok Ads API connection. Performance
> figures are entered by a human into `testing-queue.csv`. If a column is empty,
> the honest answer is "unmeasured" — the Growth Analyst is instructed never to
> estimate.
