# Brief — 001 Example

> Worked example using a fictional reusable-bottle brand. Delete once you have
> your own campaign. It exists so the pipeline has something to run against
> before you have filled in your real company files.

| Field | Value |
|---|---|
| **Angle** | Problem-first |
| **Audience** | 22–30, urban, owns and has lost several bottles |
| **One idea** | The bottle you stop replacing |
| **Offer** | None — awareness only |
| **CTA** | "12-year warranty" as an end card |
| **Length** | 8 seconds, single clip |
| **Format** | 9:16, 720p |

## Constraints carried from brand/index.md

- No exclamation marks
- No competitor names, no discounts, no sustainability guilt
- Cold morning light, matte surfaces, domestic setting

## What would make this a failure

An ad that could have been made by any bottle brand. If the hook survives
swapping the product for a competitor's, it is not specific enough.
