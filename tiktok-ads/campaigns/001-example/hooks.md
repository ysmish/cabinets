# Hooks — 001 Example

Five angles, twelve words maximum each. One gets chosen by a human before
anything is generated.

| # | Angle | Hook | Chosen |
|---|---|---|---|
| 1 | Problem-first | Your last four bottles are in a landfill | ✅ |
| 2 | Ritual | The only thing on my desk that never gets replaced | |
| 3 | Contrarian | Reusable is not a personality | |
| 4 | Objection | Yes it is heavier. That is the point. | |
| 5 | Demonstration | Upside down in my bag for an hour | |

**Chosen: #1.** Opens on the customer's own history rather than the product,
and the visual is immediate.
